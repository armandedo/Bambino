# 8. Open business questions

The design accommodates each of these without schema changes. Where a phase could not wait, a clearly labelled
placeholder is used, collected in `packages/config/src/policies.ts` so a decision is a one-line change. Questions 1, 3, 6, 9 and 13 currently run on placeholders (see the Phase 5 report).
